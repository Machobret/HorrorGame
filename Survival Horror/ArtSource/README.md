# Source art

Keep editable masters, original references, licensing/provenance, prompts and asset-specific generation recipes here. The corresponding runtime files live under `Assets/Game`.

Historical review bundles are retained for traceability. New reproducible review captures and logs belong under `Exports/Reviews/<Feature>`; shared automation belongs in `Tools`.

See [asset organization](../Docs/AssetOrganization.md). Existing recipes may require external source packs, Blender or local audio files.
