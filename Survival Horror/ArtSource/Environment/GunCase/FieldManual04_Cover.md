# Field Manual No. 04 cover

The runtime cover is rendered in Blender from the game's Gun.fbx and its existing PSX albedo. The supplied vintage manual cover guided the exterior ink contours and printed grip shading. The title and orange A-04 details belong to ExaltFall. Unity displays the game controls separately. The paperback treatment adds a creased spine, folded corners, aged page edges and mottled print.

Run render_field_manual_cover.py in Blender background mode. Pass the Unity project root and a destination directory after the argument separator. The renderer uses Windows Arial Bold and writes FieldManual04_Cover.png.

## Original concept

The original silhouette cover was generated with the built-in ImageGen tool.

No character, no instructions, no step panels, no controls, no cutaways, no extra text, modern branding, watermarks, or background outside the paper.
