EXALTFALL UI ASSET KIT

Files
- ExaltFall_TextPanel_2048x1024.png: transparent text-holder panel.
- ExaltFall_TextPanel_9slice.json: suggested scalable-border values.
- ExaltFallUI-Regular.ttf: primary UI, descriptions, subtitles and prompts.
- ExaltFallUI-Bold.ttf: headings, item names and selected states.
- ExaltFallUI_Atlas_64.png + ExaltFallUI_Atlas_64.json: ASCII bitmap font atlas and metrics.
- ExaltFallUI_Specimen.png: visual usage reference.
- FONT_LICENSE.txt: font-base license information.

Recommended styling
- Body text: Regular, 22–28 px at 1080p.
- Item names/headings: Bold, 24–32 px, tracking 2–4%.
- Color: #D8D9D6 at 92–100% opacity.
- Secondary text: #898D8C at 85–95% opacity.
- Warning/accent: restrained oxidized red #8B3835.
- Shadow: black, 55% opacity, 1–2 px downward offset.
- Avoid heavy distress inside the glyphs; keep the interface readable at small sizes.

The panel is intentionally texture-rich but text-free. For best resizing, use the
9-slice values and keep the corners unscaled.
