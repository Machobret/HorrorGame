# Material library

Materials live under Assets/EnvironmentAuthoring/Content/Materials. Files and main-object names use **M_Surface_Description_Variant**, for example M_Brick_Red_01. Surface describes the finish, not whether it is assigned to a wall, trim or floor. Mapping and repeat dimensions remain material properties.

- Surfaces/<Surface>: 32 curated finishes, including two path-UV paving alternatives. Use a path-UV finish when paving should follow road/sidewalk direction.
- Candidates/<Surface>: six photo-repeat candidates retained for evaluation. Directional artwork and visible joins prevent treating them as unqualified defaults. Existing references remain.
- ModelSpecific/Fences: 13 baked finishes, including alpha chain-link. These depend on authored model UVs and are not general repeat surfaces.
- ModelSpecific/Openings: four door/window atlas materials. Choose pictures through the insert-family selector rather than applying the whole atlas to a wall.
- Examples: four shared textured finishes (brick, plaster, wood and planks), excluded from the curated picker. Walls and trims share the same plaster and brick materials; there are no separate mapping or flat-colour examples.

The small **…** button beside wall material fields offers All wall finishes and surface categories (Brick, Concrete, Plaster, Stone, Tiles, Wallpaper, Wood, Marble and Metal), then opens Unity's native material browser with previews. All construction materials remains available for glass, frames and other family roles. Other material fields browse the Construction label directly. The object field still accepts custom/baked materials. Opening the browser alone never creates an override. Reset restores inheritance.

Wall finish filtering uses `WallFinish` and `WallFinish_<Surface>` labels, alongside the existing Construction/Surface labels. **Tools > Environment > Materials > Refresh wall finish catalog** updates the catalog and converts the explicitly selected Classic64 repeating brick, concrete, plaster and stucco wall finishes in place. Conversion preserves material GUIDs, base texture/tint/tiling, supported standard normal inputs, smoothness and face culling. Alpha cutouts, transparent, metallic, emissive, detailed and other unsupported source materials are skipped. Baked atlases and vendor materials are not conversion targets. Existing projected finishes retain their chosen mapping. Explicit source reimport can restore generated shader defaults; refresh the catalog again afterward.

The 2026-11-12 catalog refresh converted 39 existing Game environment materials and exposed 66 wall finishes. The alpha-cutout Classic64_BrickSmallRed2 material was retained on URP Lit. No material assets were duplicated or moved.

These newly converted wall finishes use **Wall projection**, with a 2 m U repeat and 2.8 m vertical repeat anchored to the wall bottom. Their physical repeat can be tuned per material. A Roughness multiplier preserves scalar source smoothness when no packed surface map is supplied; its default of 1 preserves existing packed-map materials. Render face preserves the source's culling choice; existing materials default to Back culling.

The initial organization retained all 69 material GUIDs. The 2026-11-10 example consolidation removed 13 redundant materials, leaving 56 library materials. The four retained examples keep their original GUIDs and filenames: M_Brick_SampleWall_01, M_Plaster_SampleWall_01, M_Wood_SampleUV_01 and M_Wood_PlanksSampleUV_01. Duplicate/flat plaster references now use the shared plaster; flat wood uses the shared wood. Concrete and placeholder grass/ground swatches use the existing Surfaces/Concrete/M_Concrete_Grey_01 finish. This intentionally replaces the demo colours with textured surfaces. Reference scenes and the town fence catalog were updated without regenerating geometry. Sample builders reuse these finishes and no longer create mapping copies or fallback colour swatches. All 80 fence FBXs remap their 105 imported material occurrences to the 13 shared baked finishes instead of exposing per-model copies.

Each textured example assigns its existing matching Unity Normal Map texture, with Use standard normal map enabled and Normal strength = 1. The shader decodes Unity's platform-specific normal format before applying the same UV/wall/box/triplanar normal frame as packed surfaces. Packed surface maps remain linear data and work as before when the standard-normal option is off. No extra normal textures were generated. Construction Material creation preserves supported normal inputs when copying a selected material.

The separate Procedural Generation project's Tools/ConstructionAssets/MaterialNames.json records the original source-recipe naming and curation; that recipe is not installed here. This project's ArtSource/Environment/Fences/Names.json owns normalized fence naming and material classification. ConstructionSources.json and FenceSources.json carry current native destinations under Assets/EnvironmentAuthoring/Content. See ArtSource/Environment/Fences/README.md for the GUID-preserving maintenance commands. Explicit source reimport retains its existing contract of restoring generated defaults; duplicate a finish before making independent artist-owned variations. Naming maintenance preserves shader settings.

Fence materials consistently use M_Material_SubjectAtlas_Variant. In particular, M_Concrete_SlabFenceAtlas_01 is the original precast slab atlas, previously misclassified as M_Wood_PanelsBaked_01. Native family/model/prefab/texture names now describe material and role; original source labels and hashes remain in provenance.

This selection is a starting library, not a promise of seamless patterns on every angle. World triplanar mapping can blend directional details on diagonal faces. Authored UV and path mapping remain available.

The supplied Rusty Metal 04 finish is `Surfaces/Metal/M_Metal_Rusty_04.mat`, labelled Construction and Surface_Metal. It uses URP Lit with authored UVs, an sRGB albedo, an OpenGL normal map, and a linear packed metallic/smoothness map (R = metallic, A = 1 - roughness). This preserves the supplied metal response; it does not use the nonmetallic wall projection shader. Source maps, including unused displacement, and archive provenance are preserved in `ArtSource/Environment/RustyMetal04`. This addition brings the library to 57 materials.

The two supplied wall-panelling finishes are `Surfaces/Wallpaper/M_Wallpaper_StripedWoodPanelling_01.mat` and `M_Wallpaper_PatternedWoodPanelling_01.mat`, labelled Construction and Surface_Wallpaper. Their original 256-pixel images use point filtering with mipmaps and no compression. Both use Wall projection with bottom anchoring and a 2.8 m horizontal/vertical repeat, preserving the square artwork and lower wood band. Shorter walls crop; taller walls repeat. Only albedo was supplied; no normal or height maps are assigned. Original files and provenance are under `ArtSource/Environment/WallPanelling`. The library now contains 59 materials.

As of 2026-11-09, shared construction/sample/path finishes default to Triplanar for reuse on walls, slabs and trims. Retained SampleUV/PathUV filenames preserve references and do not select mapping. Baked ModelSpecific materials remain unchanged. Repeat dimensions and scale are shared material properties; duplicate a finish for independent tuning. Triplanar is world aligned, so paving no longer follows a winding path unless an explicit Authored UV material is selected.

For performance, prefer Wall projection for planar architectural walls, Authored UV for directional paving/baked models, and Box projection for hard-surface pieces that need different planes without blending. Reserve Triplanar for shapes where blended projections materially improve the result. In this shader, Authored UV/Wall/Box sample color and packed surface once (two texture reads, three with a separate standard normal map); Triplanar samples each on three axes (six or nine reads), plus blending and normal-frame work. These counts exclude lighting and shadow sampling and are not frame-time measurements. All modes share the shader, but only materials choosing Triplanar execute its three-axis branch. Existing triplanar assignments were not changed by the wall catalog update.

Projected vertical faces default to **Start vertical tiling at wall bottom**, with **Vertical repeat (metres) = 2.8**. The shader divides height above the bottom by the repeat distance, so shorter walls crop and taller walls repeat without stretching or compression. Separate wall/head bands share the same anchor; save/reopen, moving the House and Boolean cuts preserve it. Disable the bottom anchor to register repeats to world zero. Ground/top projections keep world-space tiling, and Authored UV materials retain their UVs. **Crisp point sampling** is optional per material; it is enabled for the owner-supplied clean brick without changing other materials filtering defaults.
