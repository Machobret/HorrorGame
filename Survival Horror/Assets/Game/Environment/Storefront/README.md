# Storefront glass walls

Select **Sources/Wall_Storefront.asset** as a House's exterior/default wall family or a per-wall family override. This is a separate complete wall family, not a window insert family. Existing opaque families and project creation defaults are unchanged.

The corrected Models1.blend objects provide three solid modules (0.5, 1 and 2 m) and two doorway surrounds (1 and 2 m). They retain their 2.8 m height and original apertures. Actual framing thickness is 150 mm, so exports use **Wall_Storefront_*_T150.fbx**, family ID **Storefront**, and connection depths **−0.075 / +0.075 m**. The original Blender names still say T300; only normalized export copies are renamed. There are no window insert catalogs or additional window models in this family.

Storefront definitions disable **Cover Slab Edge**. A 2.8 m ceiling therefore produces a 2.8 m storefront, with native framing proportions and corner-cover height. The ordinary opaque-wall behavior extends the wall head over the slab edge (2.995 m for 2.8 m headroom with a 0.2 m slab); that extension deformed glazed framing and is not used here. Taller/shorter authored levels still use the engine's normal height fitting. Existing opaque definitions retain slab-edge coverage.

Submesh 0 is opaque framing and reuses **EnvironmentAuthoring/Content/WallKits/FramedWindows/M_Frame_Painted_01.mat**. Submesh 1 is the authored glass surface(s), sharing **Game/Environment/Windows/GravelGlass/GravelGlass.mat** with the updated windows. Edit that material for glass tint, opacity, normal strength and **Gravel scale (repeats / metre)**. Increasing scale makes the bumps smaller. The shader projects in world space, so pane dimensions, UVs and object scale cannot stretch the grain. Single-surface glass renders from either side; opaque frame geometry remains intact.

House Properties shows **Frame** and **Glass** for storefront walls. Each role inherits its material assignment from **Wall_Storefront** family defaults. A selected wall can override either role; **Reset** removes that assignment and restores inheritance. Multi-selection groups different families separately. Expand **Family defaults (shared)** to edit the defaults for all Houses using this family; the level Defaults view also exposes them. House/room Inside/Outside finishes apply to ordinary wall families. Storefront roles always follow their mesh regions, even when wall direction reverses, and corner covers use Frame. Material assignment changes retain generated geometry. Editing a material's shader values changes all its consumers; use a separate material asset for independent per-wall optical settings.

**Glass_DoorFamily → Clean → Glass door** contains only the requested `Insert_Door_01_W1000_H2800_Model01_Body` from Models1.blend. Its owned export is `Sources/Insert_Door_01_W1000_H2800_ModelStorefront.fbx`. It fits both storefront doorway widths, preserves the single glass pane and opaque frame, and inherits the host wall's Frame/Glass roles including overrides. It is a visual insert, without door interaction scripts. Existing door models in other families are unchanged.

This is a shared standard-sized door, not a storefront-only insert. Import appends its catalog to every existing wall family with a matching doorway (including Wall_01, Wall_02 and GravelGlass_WallFamily), retaining their existing catalog order and choices. Ordinary walls use the door preset's own frame/glass materials; a host with named roles can supply its defaults/overrides. New custom families can add **Glass_DoorFamily** to their Opening Families list; compatibility still requires the matching 0.9 × 2.1 m aperture and centered 1 m/2 m segment metadata.

Normal engine wall collision is retained, including the doorway apertures. Glass is not breakable or interactive. Screen-space refraction retains the shared material's limitations for other transparent objects and off-screen content.

To rebuild, run `ArtSource/Environment/Storefront/export_storefront.py` in headless Blender with `--source C:/Users/manta/Downloads/Models1.blend --project <project>` after `--`, then invoke **Tools → Environment → Storefront → Import T150 glass family**. This explicit import reconnects the selected door catalog and creates missing named defaults; it preserves existing family material assignments, catalog/module GUIDs and shared glass-material settings. Source/provenance live in ArtSource; validation and captures live in ignored `Exports/Reviews/MaterialRolesWorldGlass`. Rebuild the affected House to update existing generated geometry from corrected source normals. Existing placed openings retain their explicit model selection; select the storefront door catalog to replace an older door.
