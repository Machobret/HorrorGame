# Lighter

Survival PSX metal Zippo lighter, shown with its authored open lid. Drag `Lighter_Pickup.prefab` into a scene for native pickup, inventory splash, examination and dropping. It is tagged `Lighter` / `PuzzleItem`; ignition and puzzle effects are left for later.

Rebuild assets: **Horror Game > Items > Build Lighter**. Validation runs automatically and is also available under **Validate Lighter**. The builder registers the item/drop prefab in the active Horror Engine databases, preserving existing IDs when rebuilt.

Editable Blender model and deterministic pixel-art generation: `ArtSource/Items/Lighter/import_survival_zippo.py`. Exported icon can be replaced with **Horror Game > Items > Icon Studio**.
