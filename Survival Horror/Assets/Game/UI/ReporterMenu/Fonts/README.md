# Reporter Menu typography

The Reporter Menu uses Special Elite by Brian J. Bonislawsky (Astigmatic), copyright 2010. The original TTF and Apache 2.0 license come from [Google Fonts](https://github.com/google/fonts/tree/main/apache/specialelite).

The theme's Interface Font applies to every label, including descriptions, transcripts, and the condition text. The Special Elite TextMesh Pro asset uses a static, bilinear signed distance field atlas for the font's Latin glyphs. The project's localization bootstrap supplies Noto Sans KR as a fallback for Korean glyphs. An unset Interface Font uses the project's default Liberation Sans.

The W95FA trial came from [FontsArena](https://fontsarena.com/w95fa-by-alina-sava/). Alina Sava distributed it under the SIL Open Font License 1.1 with the accompanying `OFL.txt`.
